# Quarantine procedure

A quarantined lot is blocked from shipment until a reviewer clears it.
Quarantine is applied when a temperature excursion or a missing certificate is found.
Quarantine release is a Tier 3 mutation and needs approval. See [[POL-HITL-010]].
