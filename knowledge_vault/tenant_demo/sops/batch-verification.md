# Batch verification procedure

1. Confirm the lot identifier matches LOT-00000.
2. Confirm the certificate of analysis is attached to the lot record.
3. Confirm the temperature log shows no excursion above 8 degrees Celsius for more than 30 minutes.
4. Record the verifier identity and the time of verification.

Verification that fails any step must be escalated. See [[SOP-QUAR-004]].
