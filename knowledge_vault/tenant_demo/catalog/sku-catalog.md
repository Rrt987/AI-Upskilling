# Product SKU catalog

SKU identifiers use the format SKU-000 to SKU-999999 (three to six digits).
SKU-099 is the cold-chain sensor kit. SKU-120 is the batch label printer.
Refer to [[SOP-VER-002]] for the verification steps that apply to SKU-099 lots.
